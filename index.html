Drop File to Open

CSV, JSON, SQLite, and Excel files are supported

Use File > Open, the Open File button, or drag and drop a file to load CSV/JSON/SQLite/XLSX.

Use field:value, AND, OR, NOT, parentheses, and regex with /pattern/
Help

Timeline Exploder is a simple, web-based utility for browsing CSV, JSON, SQLite, and Excel files. It is heavily inspired from Eric Zimmerman's Timeline Explorer.

All processing is handled on the client-site, no data is sent to any server.

Keyboard shortcuts:
Cmd/Ctrl+O: Open file
Cmd/Ctrl+F: Show find bar
F3 / Shift+F3: Next/Previous find match
Alt+G: Focus global search
Alt+F: Clear filters
Alt+V: Copy visible rows
Alt+S: Copy selected rows
Alt+B: Clear grouping

The source code can be found on GitHub.
